# ZXing.Net

`zxing.dll` é o arquivo original `lib/net48/zxing.dll`, sem modificações, do pacote ZXing.Net 0.16.11. É usado para gerar o QR localmente.

- [Pacote oficial NuGet](https://www.nuget.org/packages/ZXing.Net/0.16.11).
- [Fontes](https://github.com/micjahn/ZXing.Net), copyright ZXing.Net authors, licença Apache 2.0 em `licenses/ZXing.Net-COPYING.txt` na raiz do projeto.
- SHA-256 da DLL: `52f00a43f9574a411009899a6236f3efb5b597fbae0f3163dfec9cbb0c1f4d38`.
- SHA-256 do pacote NuGet usado: `7d39234d668e558b3d374d18116ed57021d7c0df482801f1e1db4f1db9314ec3`.

O script de build verifica o hash da DLL e a copia para junto do EXE. Distribua os dois arquivos juntos, acompanhados da licença.
