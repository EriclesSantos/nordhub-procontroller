# ZXing Core

Biblioteca Java original, sem modificações, para leitura local de QR Code.

- Versão: 3.5.4.
- [Artefato oficial Maven Central](https://repo.maven.apache.org/maven2/com/google/zxing/core/3.5.4/core-3.5.4.jar).
- SHA-256 do arquivo incluído: `71de5d89341b5fcf5dd89da7f44e84d825d0e084cdf3ec77c9abe26b0f0ceb13`.
- [Fontes](https://github.com/zxing/zxing/tree/zxing-3.5.4), copyright ZXing authors, licença Apache 2.0 em `licenses/ZXing-APACHE-2.0.txt` na raiz do projeto.

A inclusão local permite compilar sem baixar esta dependência novamente. Imagens da câmera não são enviadas a serviços externos.
